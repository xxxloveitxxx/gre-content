# **App Name**: SocialForge

## Core Features:

- AI Content Generation: Generate tailored social media posts (text, hashtags, emojis) for specified platforms based on user-provided topics or keywords, utilizing Groq AI as a powerful tool.
- Platform Selection: Allow users to select target social media platforms (e.g., X/Twitter, Instagram, LinkedIn, Facebook) for content generation, influencing the AI's output style and length.
- Content Editor & Review: Provide an intuitive interface for users to review, edit, and refine AI-generated content before it's saved or scheduled.
- Content Library: A centralized dashboard to store, organize, search, and manage all generated content, including drafts and approved posts.
- Basic Content Status & Tracking: Enable users to mark content with simple statuses like 'scheduled' or 'posted' and associate basic date/time information for organizational purposes.
- Prompt Management: Allow users to save and easily reuse custom prompts or content templates for consistent and efficient content generation.

## Style Guidelines:

- Primary color: A vibrant, professional blue (#2684D6), representing communication and innovation. This color is balanced to stand out on a light background.
- Background color: A very light, desaturated blue (#EEF3F7), providing a clean and calming canvas that minimizes visual distraction and enhances content readability.
- Accent color: A refreshing, slightly brighter blue-green (#68D0D0), analogous to the primary color, used for interactive elements and highlights to draw attention without being overwhelming.
- All text will use 'Inter', a grotesque-style sans-serif font. Its modern, objective, and highly legible design ensures clarity and professionalism across all content, from headlines to body text.
- Utilize modern, clean line icons with a minimalist aesthetic, visually communicating social media platforms, content types, and application features efficiently without clutter.
- Implement a clean, organized, and responsive dashboard layout that prioritizes content previews and editing, ensuring intuitive navigation and an efficient workflow.
- Incorporate subtle and smooth transition animations for content loading, panel expansions, and status updates, enhancing user feedback and the overall interactive experience.
